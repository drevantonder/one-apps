# One Plugins

Plugins for [The One App](https://github.com/drevantonder/the-one-app) that I made for my own network and share:
one folder each in `plugins/`, whose `SKILL.md` says what it does.

Install one in your network:

    one install drevantonder/one-plugins --plugin <name>

Or deploy one from a checkout of this repo:

    one deploy --name <name> --files-from plugins/<name>
